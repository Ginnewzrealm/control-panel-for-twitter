## Default listing (English)

### Name

Control Panel for Twitter · 宽屏私人版

### Summary

Private wide-layout fork with interface controls for X/Twitter.

### Description

Control Panel for Twitter · Wide Private Edition expands supported X/Twitter pages to use the available content width while retaining the original extension's interface controls and customization options.

This is an independent private fork of the MIT-licensed Control Panel for Twitter project. It is not affiliated with, endorsed by, or produced by the original author or X Corp.

The extension runs only on X/Twitter pages and stores settings locally on the user's device. It may locally read or modify X/Twitter page requests and responses, and selected features may make requests to X/Twitter APIs using the user's existing session. It does not collect, sell, or share personal information or browsing activity with the developer or with developer-operated services.

### Single purpose

Customize the X/Twitter interface and expand supported pages to use the available content width.

### Permission justifications

- `storage`: Stores the user's extension settings locally with `chrome.storage.local`.
- `https://twitter.com/*`, `https://mobile.twitter.com/*`, `https://x.com/*`, `https://mobile.x.com/*`: Applies the user-selected interface and layout changes on supported X/Twitter pages.

### Reviewer test instructions

1. Install and enable the extension.
2. Open an X/Twitter history, notifications, profile, list, community, explore, or individual post page.
3. Confirm that the right search sidebar is hidden on supported pages and the main content column expands to use the available width.
4. Open the extension options to confirm that settings are saved locally after a page refresh.

No credentials are provided or required by the extension. Some X/Twitter pages may require the reviewer to use their own X account.

## 中文商店信息

### 名称

Control Panel for Twitter · 宽屏私人版

### 简短说明

为 X/Twitter 提供界面控制和宽屏内容布局的私人分支。

### 详细说明

Control Panel for Twitter · 宽屏私人版保留原扩展的界面控制与自定义功能，并让受支持的 X/Twitter 页面充分使用可用的内容宽度。

这是基于 MIT 许可的 Control Panel for Twitter 项目修改而成的独立私人分支，与原作者及 X Corp. 无隶属、授权或背书关系。

扩展仅在 X/Twitter 页面运行，设置保存在用户设备本地。扩展可能在浏览器本地读取或调整 X/Twitter 页面请求与响应；部分可选功能可能使用用户现有的 X/Twitter 会话请求 X/Twitter API。扩展不会向开发者或开发者运营的服务收集、出售或共享个人信息及浏览活动。

### 单一用途

自定义 X/Twitter 界面，并让受支持的页面充分使用可用的内容宽度。

### 权限说明

- `storage`：使用 `chrome.storage.local` 在本地保存用户的扩展设置。
- `https://twitter.com/*`、`https://mobile.twitter.com/*`、`https://x.com/*`、`https://mobile.x.com/*`：在受支持的 X/Twitter 页面应用用户选择的界面及布局调整。

### 审核测试步骤

1. 安装并启用扩展。
2. 打开 X/Twitter 的历史记录、通知、个人资料、列表、社群、探索或具体贴文页面。
3. 确认受支持页面的右侧搜索栏被隐藏，主内容栏扩展到可用宽度。
4. 打开扩展选项，修改设置并刷新页面，确认设置保存在本地。

扩展本身不需要也不提供任何登录凭据。部分 X/Twitter 页面可能要求审核人员使用自己的 X 账号。
